# RTEC-GTW-Planner
For Arborist to record itemized proposal/ work plan details and doodled photos. outputs pdf report with pictures

## Field guide (internal)

`_field-guide/` holds the SOP and demo walkthrough for this app — field
capture, the export bundle, the OneDrive hand-off and the SingleOps proposal
build. It is **excluded from the GitHub Pages build** and must stay that way:
the published site is public even while this repository is private, and the
guide contains pricing, deposit terms, catalog codes and photos of client
properties. See `_field-guide/README.md`.

Do not add a `.nojekyll` file — it would disable Jekyll and start publishing
`_field-guide/` to the open internet.
