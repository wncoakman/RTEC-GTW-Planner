## Its worked example

three trees, eight priced lines, grand total $10,585.00. The client is
fictional; the street is a real one in Arlington so the satellite site map is
genuine. Source photos are past RTEC jobs with their burned-in captions
cropped off.

The current guide uses a different worked example (41827 / Whitfield, Dana /

## Why it was kept

Its three recordings and its example bundle cover the same ground the current
guide covers with seven recordings, but the prose is independently written.
If something in the current guide reads thin, the wording here is worth
checking before rewriting from scratch.
